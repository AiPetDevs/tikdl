# TikDL

Простое приложение: скачивать и раздавать файлы и папки по ссылке на базе [iroh](https://iroh.computer).
Пауза и докачка (в том числе после перезапуска), пробивание NAT, relay, когда прямое соединение невозможно.

## Для получателя
1. Установить TikDL (.dmg для Mac, .exe для Windows).
2. Нажать на ссылку `tikdl://get/...`: приложение откроется и спросит «Скачать?» (имя, размер, от кого).
   Или вставить ссылку в поле и нажать «Скачать». Существующие файлы не перезаписываются: «имя (1)».
   Скачанное не раздаётся дальше: оно лежит в отдельном хранилище, которое в сеть не отдаётся.
3. «Пауза»/«Продолжить» в любой момент. Если закрыть приложение, при следующем запуске загрузка продолжится
   сама с того же места; список загрузок сохраняется. Внутренняя копия скачанного удаляется автоматически.

## Для раздающего
- В приложении: вкладка «Раздать» → файл или папка → «Скопировать ссылку». Раздача идёт, пока приложение открыто,
  и возобновляется при его запуске. «Остановить» — ссылка перестаёт работать сразу.
  Если исходный файл изменили или удалили, раздача помечается «Не раздаётся» — раздайте его заново.
- Из папки не раздаются скрытые и служебные файлы (`.git`, `.env`, `.DS_Store`, `Thumbs.db`, `desktop.ini`);
  приложение покажет, сколько пропущено. Явно выбранный файл раздаётся всегда.
- На сервере без экрана:
  ```
  tikdl serve /путь/к/папке [/ещё/путь ...]   # раздать (без путей — продолжить прежние раздачи)
  tikdl shares                               # список раздач и их состояние
  tikdl stop <id>                            # остановить раздачу
  tikdl get "<ссылка>" /куда/сохранить        # скачать
  ```
  Консоль и окно приложения не работают одновременно (общее хранилище) — закройте одно перед другим.

Ключ узла хранится в `~/.local/share/tikdl/node.key` (macOS: `~/Library/Application Support/tikdl/`).
Файл ключа доступен только владельцу (права 0600). Повреждённый ключ откладывается в `node.key.bad`.
Пока ключ на месте, ссылки остаются рабочими при смене сети и IP. Узел слушает один и тот же порт (файл `port`),
поэтому после перезапуска старые ссылки работают сразу; в новой сети узел находится по ключу через relay за ~10–20 с.

## Сборка
- Локально: `cd src-tauri && cargo install tauri-cli --version "^2" && cargo tauri build`
- Через GitHub Actions: загрузите репозиторий и запустите workflow **build** (Actions → build → Run workflow)
  или создайте тег `v0.1.0`. Готовые .dmg (один на Apple Silicon и Intel) и .exe появятся в Artifacts
  или в Releases. На каждый push и pull request идут тесты и clippy.

## Если macOS не открывает приложение
Сборка подписана ad-hoc, без сертификата Apple Developer, поэтому при первом запуске Gatekeeper её блокирует.
Перетащите TikDL в «Программы», затем выполните в Терминале один раз:
```
xattr -cr /Applications/TikDL.app
```
Или: правый клик по приложению → «Открыть» → «Открыть».
Чтобы предупреждений не было совсем, нужны сертификат Apple Developer ($99/год) и нотаризация.

## Интерфейс

Собран по правилам ui-architect: `ui/tokens.css` → кит `ui/kit/*` (реестр `docs/UI_COMPONENTS.md`, витрина `ui/index.html#/kit`) → экраны `ui/screens/*`; данные `ui/api.js` → `ui/state.js`. Замечания владельца — `docs/UI_REMARKS.md`.

Проверки интерфейса (нужен `npm i` один раз):

    node scripts/ui_check.mjs          # литералы, сырые контролы, дубли, реестр
    npx eslint ui                      # слои: экраны без api, без стилей; размер файлов
    (cd ui && python3 -m http.server 8765 --bind 127.0.0.1 &) && node scripts/ui_smoke.mjs   # снимки в shots/
