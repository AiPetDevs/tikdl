# Симптом → где смотреть

| Симптом (что видит пользователь) | Вероятная причина | Где смотреть | Компонент |
|---|---|---|---|
| «Сеть не запустилась: хранилище TikDL уже открыто…» | открыта консоль `tikdl` на той же папке данных | закрыть консоль или запускать её с `HOME=<папка>` | core.node, app.cli |
| Старые ссылки не работают совсем | ключ узла пересоздан | есть ли `node.key.bad` в папке данных | core.node |
| Старые ссылки оживают через 10–20 с после перезапуска | сохранённый порт занят | файл `port`, stderr «порт … занят» | core.node |
| «неверный тикет» | ссылку обрезал мессенджер или это не тикет | `parse_link` в core.rs | core.links |
| «не хватает места на диске …» | на томе назначения или хранилища мало места (запас 1 % + 64 МБ) | `Node::check_space` | core.download |
| «не удалось скачать: раздача остановлена, её файлы изменились…» | у раздающего хеш не в белом списке: остановлена, изменена, запрещена или он не в сети | у раздающего `tikdl shares` | core.download, core.share |
| «раздающий не ответил за 15 с» на «Что внутри?» | раздающий не в сети, relay недоступен | `Node::peek` | core.download |
| Полоса не движется, нет доли | ссылка без размера и peek не ответил | `spawn_job`, ветка `total.is_none()` | app.jobs |
| После перезапуска загрузка не продолжилась | запись была на паузе, а не running | `downloads.json` → `state` | app.jobs |
| Место не освободилось после загрузки | GC ещё не прошёл (15 с) или сироты после аварии | размер `downloads/`, `Node::remove_orphans` | core.download |
| Раздача «файлы изменились» | исходный файл изменили, перезаписали, удалили | `shares.json` → `files[].size/mtime` | core.share |
| «это системная папка — TikDL её не раздаёт» | путь под правилом `paths::forbidden_share` | это решение владельца, не ошибка | core.paths |
| «в папке только скрытые и служебные файлы (N)» | в папке только `.`-файлы, `Thumbs.db`, `desktop.ini` | `paths::is_hidden_name` | core.paths |
| Уведомления «Готово» нет | уведомления для TikDL выключены в системе | Системные настройки → Уведомления; stderr «уведомление не показано» | app.shell |
| Клик по ссылке открывает страницу, а не приложение | TikDL не установлен или схема не зарегистрирована | кнопка «Открыть» на странице; первый запуск `.app` регистрирует схему | ui.site |
| macOS «не удаётся открыть приложение» | ad-hoc подпись, Gatekeeper | `xattr -cr /Applications/TikDL.app` (README) | delivery.ci |
| Окно не реагирует на клики при запуске агентом | запущен бинарник, а не `open`; окно на другом Space | HANDOFF.md → Traps | app.shell |
| Повторная загрузка того же содержимого падает с `Error::Io` | выкладка переносом (TryReference) | вернуть экспорт копией; docs/IDEAS_LEDGER.md | core.download |
| «ссылка уже использована на другом устройстве — попросите отправителя прислать новую» | одноразовую ссылку первым открыло другое устройство | у отправителя код устройства в строке «закреплена»; не тот — «Новая ссылка» | core.once |
| «отправитель не в сети, или ссылка уже не действует (получена, остановлена или истекла)» | отправитель выключен, или ссылка сгорела/остановлена | у отправителя `tikdl shares` | core.once |
| «ссылка недействительна — отправитель её остановил или выдал новую» | токен не совпал | у отправителя — актуальная ссылка | core.once |
| «ссылка больше не действует: файлы уже получены или истёк срок» | этап used или expired (3 дня без закрепления, 7 — без активности) | `shares.json` → `once.state` | core.once |
| «уже получено на этом компьютере — одноразовая ссылка сгорела» | эту одноразовую ссылку этот TikDL уже скачал | `downloads.json`, запись `once-…` | app.commands |
| «это ваша собственная одноразовая ссылка — откройте её на том устройстве…» | отправитель открыл свою ссылку | открыть на другом устройстве или с другим `HOME` | core.once |
| «одновременно может действовать не больше 10 одноразовых ссылок» | лимит `MAX_LIVE` | остановить ненужные | core.once |
| Одноразовая строка «подключение к сети…» без ссылки | временный узел ещё не связался с relay (ссылка без relay выдала бы IP) | сеть; ссылка появится сама | core.once |
| У отправителя не наступает «получено» | получатель не смог отправить подтверждение | у получателя `downloads.json` → `ack_pending`; повтор при его запуске | app.jobs |
| «ошибка Android (подробности в журнале)» | исключение Java при вызове через JNI | `adb logcat` | app.android |
