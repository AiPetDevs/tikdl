# Журнал замечаний владельца об интерфейсе

Формат: дословная фраза → правило → места → причина → механизм → статус.

## R1 (2026-11-23) — дубль заголовка

- **Фраза:** «Зачем два раза одно и тоже?» (скриншот: заголовок окна «TikDL» и под ним крупное «TikDL»).
- **Правило:** на экране не повторяется то, что уже показано рядом: имя программы есть в заголовке окна, внутри окна его нет; подпись раздела не повторяет текст вкладки.
- **Места:** `ui/index.html` h1 «TikDL»; карточка «Скачать»: подпись над полем повторяла подсказку — стала подсказкой в самом поле; входящая ссылка показывалась дважды (в окне подтверждения и в поле ввода) и оставалась в поле после ответа — найдено проверкой в .app; строка раздачи показывала обрезанный полный путь вместо имени — имя в строке, путь во всплывающей подсказке.
- **Причина:** страница собиралась как веб-страница, а не как окно программы.
- **Механизм:** ревью глазами по снимкам `shots/` (пункт U1 приёмки); в экранах нет `h1` — разметка экрана строится только из кита.
- **Статус:** исправлено, проверено в собранном .app.

## R2 (2026-11-23) — действия значками на самом баре

- **Фраза:** «ПРодолжить - это значок паузы, убрать - это крестик. Они должны быть на самом баре так же как и данные. прикрепил образец бара» (образец — `docs/reference/TransferBar`).
- **Правило:** действие над строкой — значок на той же строке, что и её данные (полоса с текстом «сколько из скольки · скорость» внутри): ⏸ / ▶ / ✕. Состояние — ярлык справа от имени. Разрушительное действие (✕, «остановить раздачу») срабатывает со второго нажатия. Текстовых кнопок под строкой нет.
- **Места:** карточка загрузки (Пауза/Продолжить/Повторить, Показать, Убрать — текстом под полосой; текст данных под полосой); карточка раздачи (Скопировать ссылку, Остановить/Убрать — текстом под карточкой).
- **Причина:** каждая карточка собиралась своей разметкой в `app.js`, общего компонента строки не было.
- **Механизм:** компоненты кита `TransferRow`, `ShareRow`, `ProgressPill`, `IconButton` (с подтверждением вторым нажатием), все состояния — в витрине `#/kit`; экраны строят строки только через них (сырые `button` вне кита ловит `ui_check`); сценарий U2–U4 настоящим вводом в .app.
- **Статус:** исправлено, проверено в собранном .app.

## R3 (2026-11-23) — полоса не движется

- **Фраза:** «Бар не меняется - нет полосы загрузки» (скачивание 4.1 ГБ по ссылке без имени).
- **Правило:** полоса загрузки показывает долю по любой ссылке; если размер неизвестен из ссылки, его узнают у раздающего до начала скачивания. Неизвестным размер остаётся, только если раздающий не ответил: тогда «передано N», без фальшивых 0 %.
- **Места:** загрузка по голому тикету (без `?size=&name=`): нет размера → нет доли → полоса пустая до конца; вместо имени — хеш.
- **Причина:** размер брался только из параметров ссылки.
- **Механизм:** `Node::probe` (core.rs) — размеры файлов и имя коллекции у раздающего; `spawn_job` шлёт их в событии progress и сохраняет в `downloads.json`. Сценарий U8 настоящим вводом в .app.
- **Попутно:** окно подтверждения ставило фокус на «Скачать», а ссылка выводит окно вперёд — случайный Return запускал загрузку без решения. Фокус теперь на «Отмена».
- **Статус:** исправлено, проверено в собранном .app.
