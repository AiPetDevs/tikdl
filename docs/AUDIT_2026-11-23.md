## P0 — безопасность и приватность

1. **Ссылка из браузера сразу запускает скачивание без подтверждения.**
   `ui/index.html:133` — событие `open-link` сразу вызывает `start()`. Любой сайт может открыть
   `tikdl://get/...` и без вопросов скачать в «Загрузки» что угодно и сколько угодно (вплоть до
   заполнения диска), а заодно узнать IP получателя: узел подключится к адресам из тикета.
   **Исправить:** по ссылке только заполнять поле и показывать карточку «Что: имя, размер, число файлов,
   от кого (ID узла) → [Скачать] [Отмена]».

2. **Хранилище раздаёт всё, что в нём есть, включая скачанное.**
   `BlobsProtocol::new(&store, None)` (`core.rs:58`) отдаёт любой blob по его хешу. Скачанное держится тегом
   `dl-…` (`core.rs:171`), значит получатель незаметно становится раздающим чужих файлов для всех, кто знает
   хеш, а ID узла постоянный. Раздачи `share-…` тоже живут вечно после перезапуска, а в интерфейсе их не видно
   и остановить нельзя.
   **Исправить:** передать в `BlobsProtocol` фильтр событий или запросов, который пропускает только корни
   активных раздач и их дочерние хеши. Скачанное по умолчанию не раздавать. Добавить список «Мои раздачи»
   с кнопкой «Остановить» (удаляет тег `share-…`).

3. **В раздачу папки уходит всё содержимое: `.git`, `.env`, `.DS_Store`, ключи.**
   `core.rs:81` — `WalkDir` без фильтра. **Исправить:** по умолчанию пропускать скрытые и служебные файлы,
   перед созданием ссылки показывать список файлов и общий размер.

4. **Ключ узла записан с правами по умолчанию (0644).** `core.rs:43`. Другой пользователь компьютера может
   прочитать ключ и выдавать себя за этот узел. **Исправить:** на Unix ставить права 0600, писать атомарно
   (временный файл, затем rename). Повреждённый ключ сейчас молча заменяется новым (`core.rs:37-42`), и все
   старые ссылки ломаются без предупреждения: нужно хотя бы писать об этом в лог.

5. **CSP отключён (`"csp": null`) при `withGlobalTauri: true`.** Любая XSS сразу получает `invoke`,
   то есть раздачу любого пути (`share_path` принимает произвольную строку). Экранирование `esc()` сейчас
   применяется везде, но защиты второго уровня нет. **Исправить:** задать
   `"csp": "default-src 'self'; style-src 'self' 'unsafe-inline'"`, а скрипт вынести в отдельный `.js`.

6. **Скачивание молча перезаписывает файлы в папке назначения.** `core.rs:183` — `export` поверх
   существующего файла. Ссылка с именем `Documents/важное.docx` перезапишет такой же файл в «Загрузках».
   **Исправить:** при совпадении имени добавлять суффикс «(1)» или скачивать во временную папку, а потом
   переименовывать.

## P1 — надёжность и корректность

7. **Второй экземпляр приложения (Windows и Linux).** Клик по ссылке, когда TikDL уже открыт, запускает вторую
   копию, а не передаёт ссылку в первую. Вторая копия упрётся в заблокированное хранилище и тот же ключ узла.
   Нужен `tauri-plugin-single-instance` с функцией `deep-link`, это штатный способ Tauri v2.
   То же касается CLI `get`/`serve`, если приложение открыто: одно хранилище, один ключ, два процесса.

8. **«Загрузка продолжится после закрытия приложения» — обещание README не выполняется.**
   Недокачанные блоки в хранилище остаются, но список загрузок живёт только в памяти страницы (`jobs` в JS).
   После перезапуска не видно ни списка, ни автопродолжения: ссылку надо вставлять заново.
   **Исправить:** хранить загрузки (ссылка, папка, состояние) в `data_dir/jobs.json` и при старте
   восстанавливать их на паузе или продолжать.

9. **Раздачи не возобновляются после перезапуска.** Узел запускается лениво, при первом вызове команды
   (`main.rs:18`). Теги `share-…` на месте, но пока пользователь ничего не нажмёт, узел не в сети и ссылки мертвы.
   Это противоречит комментарию в `core.rs:121`. **Исправить:** запускать узел в `setup()` и выводить статус
   (онлайн / relay / прямое соединение).

10. **Двойной расход диска и хранилище без чистки.** Скачанное лежит в `store` и ещё раз копией в «Загрузках».
    Для файла на 50 ГБ нужно 100 ГБ, а `data_dir/store` только растёт: удаления и GC нет.
    **Исправить:** экспортировать через `ExportMode::TryReference` (перенос вместо копии), после экспорта
    снимать тег `dl-…` и вызывать GC. В настройки добавить «Очистить кэш (N ГБ)».

11. **TryReference при раздаче: изменили исходный файл — раздача сломалась.** Хеш посчитан от старого
    содержимого, и получатель увидит невнятную ошибку проверки. Нужно предупреждение в интерфейсе или проверка
    mtime/размера с переиндексацией.

12. **Пауза = `abort()` задачи** (`main.rs:144`). Если пауза попала на этап экспорта, в «Загрузках» останется
    недописанный файл, который выглядит целым. Гонка: пауза сразу после «Готово» отправляет событие `paused`,
    и в карточке готовой загрузки появляется «На паузе». **Исправить:** отмена через `CancellationToken`,
    проверяемый между этапами. Экспорт либо не прерывать, либо писать во временный файл с последующим rename.

13. **Прогресс и скорость считаются неверно (проверить).** Скорость — средняя от старта, а не текущая.
    При докачке `Progress(n)`, скорее всего, считает только новые байты, и полоса начинает с нуля.
    `total` берётся из `?size=` в ссылке — это непроверенные данные отправителя, могут быть неверными или
    отсутствовать (у «голых» тикетов sendme его нет, тогда 0 % до конца). **Исправить:** после загрузки
    корня коллекции брать реальные размеры из неё, скорость считать скользящим окном за 3–5 с.

14. **Ссылка при старте приложения передаётся через `sleep(800ms)`** (`main.rs:231`). На медленной машине
    страница не успеет подписаться, и ссылка потеряется. **Исправить:** команда `take_pending_links`,
    которую страница вызывает сама после загрузки.

15. **Мелочи в коде:** `jobs` в `AppState` не чистится от завершённых задач. Метаданные `std::fs::metadata`
    читаются отдельно от импорта (`unwrap_or(0)` прячет ошибку). Хеширование при раздаче идёт по одному файлу
    и без прогресса: на большой папке окно «висит» с одной строкой текста.

## P1 — сборка и выпуск

16. **`macos-13` в CI.** GitHub вывел эти раннеры из эксплуатации, задача для Intel Mac упадёт или зависнет.
    Собирать Intel на `macos-latest` с `--target x86_64-apple-darwin` или сразу `universal-apple-darwin`
    (один .dmg для обеих архитектур).
17. **Для релиза нет `permissions: contents: write`.** С настройками токена по умолчанию
    `softprops/action-gh-release` получит 403.
18. **`cargo install tauri-cli` в каждой задаче** — лишние ~5–8 минут. Лучше `tauri-apps/tauri-action`
    или кэш бинарника.
19. **Нет тестов, `clippy` и `fmt` в CI.** `parse_link` и `safe_join` тестируются за минуты, особенно
    `safe_join` на Windows (`..\..`, `C:`, `CON`, `NUL`, имена с `:` и точкой в конце).
20. **Подпись.** На macOS ad-hoc подпись, на Windows подписи нет (SmartScreen). Для узкого круга
    достаточно инструкции из README. Для широкой раздачи нужны Developer ID с нотаризацией и сертификат
    для Windows (или Azure Trusted Signing — дешевле).
21. **Нет автообновления.** `tauri-plugin-updater` и `latest.json` в релизах. Иначе исправления
    безопасности до пользователей не дойдут.

## P2 — удобство

22. **Ссылки `tikdl://` не кликабельны в большинстве мессенджеров** (Telegram, WhatsApp, почта их не
    подсвечивают). Нужна https-страница-прокладка вида `https://<домен>/g#<тикет>`: она открывает приложение,
    а если его нет, предлагает скачать. Тикет в `#` не попадает на сервер.
23. **Тикет раскрывает IP-адреса раздающего** (прямые адреса в `endpoint().addr()`). Добавить переключатель
    «только relay-адрес в ссылке»: соединение всё равно найдётся по ID узла.
24. **Перетаскивание файлов в окно**, выбор нескольких файлов сразу, QR-код ссылки (для телефона),
    системное уведомление «Готово», иконка в трее, чтобы раздача шла при закрытом окне.
25. **Перед скачиванием показывать состав** (файлы, размер — из коллекции, а не из `?size=`),
    запоминать последнюю папку назначения, очищать поле после старта.
26. **Карточка раздачи:** «Остановить», «Показать в Finder», счётчик скачиваний (через события
    `BlobsProtocol`).

## Что сделано хорошо

- `safe_join` защищает от `../` в именах из чужой коллекции.
- Постоянный ключ и FsStore — правильная основа для стабильных ссылок и докачки.
- `TryReference` при раздаче: большие файлы не копируются в хранилище.
- Экранирование всех строк в HTML и раздельные режимы GUI / `serve` / `get` в одном бинарнике.
- Компактный, читаемый код без лишних слоёв.
