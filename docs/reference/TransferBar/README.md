# TransferBar — полоса передачи файлов из Lab

Вырезка из Lab («Файлы»): очередь копирования на rsync и её вид — полоса с текстом внутри, кольцо у файла, карточка
с ⏸ ▶ ✕. Пакет Swift без зависимостей, macOS 14+, SwiftUI. Картинка всех состояний — `states.png`.

## Как устроено

**Три слоя, каждый можно взять отдельно.**

1. `RsyncProgress` — разбор вывода `rsync --progress`. rsync пишет по строке на файл и переписывает её через `\r`,
   пока файл идёт (`31457280  50%  30.00MB/s  0:00:01`); готовый файл заканчивается `\n` и `(xfer#N…)`.
   Разбор складывает: байты готовых файлов + байты текущего = «сколько передано». Остальные строки — имя файла.
   Чистая структура: кормить кусками в порядке прихода.
2. `TransferQueue` — очередь. Одна передача за раз, по порядку. У каждой состояние:
   `в очереди → идёт → (пауза | на паузе | сбой) → готово`.
   - **⏸ пауза** = заморозка: rsync и его ssh получают SIGSTOP. Связь открыта, ▶ (SIGCONT) продолжает с того же байта.
   - **на паузе** (связь пропала, приложение закрылось — `stopAll`): rsync останавливается, недокачанный кусок
     лежит у цели в скрытой папке `.partial` (`--partial-dir`), и следующий запуск дошлёт только остаток.
   - **Обрыв** при живой связи — до 3 повторов сами; потом «сбой» с последней строкой ошибки rsync.
   - **✕** — два нажатия; останавливает и удаляет `.partial`. Дошедшие целиком файлы остаются.
   - **Перенос** (`.move`): оригинал убирается только после того, как всё дошло (`removeSource` — ваш код, лучше в корзину).
   - Очередь хранится в UserDefaults: после перезапуска незаконченное возвращается «на паузе»; зеркало
     (`--delete-after`) ждёт ручного ▶ — оно удаляет по состоянию папок в момент запуска.
3. Вид (`Views.swift`):
   - `ProgressPill` — капсула, заливка = доля, текст внутри справа: «39,8 МБ из 62,9 МБ · 8 МБ/с». Размер неизвестен —
     «передано N», а не ложный 0 %. **Без анимации значения**: в Lab она перерисовывала всё окно ~12 раз в секунду
     (CPU 9 % → 2 % без неё).
   - `ProgressRing` / `TransferRing` — кольцо у бледной строки файла, который едет (как в Finder): синяя дуга идёт,
     пунктир ждёт, жёлтая пауза, красный «!».
   - `TransferRow` — карточка: что и куда, ярлык состояния, полоса, ⏸/▶ и ✕ (✕ спрашивает вторым нажатием).
   - `TransferList` — карточки столбиком (для всплывающего окна или панели).
   - Цвета и размеры — в `TBTheme` (тёмная палитра Lab), меняются присваиванием.

## Как встроить

```swift
// Package.swift: .package(path: "TransferBar"), зависимость "TransferBar"
import TransferBar

@StateObject var queue = TransferQueue(saveKey: "myTransfers")

// удалённая сторона — по ssh (rsync -e):
queue.rsh = "ssh -o BatchMode=yes"
queue.isOnline = { myLink.isUp }                 // офлайн — сбой не считается попыткой, ждём
queue.removeSource = { spec in /* в корзину */ }  // для переноса
queue.removeRemote = { cmd in /* ssh host cmd */ }// для ✕ на удалённой цели
queue.onFinish = { job in /* перечитать папку */; queue.forget(job) }

queue.add(TransferSpec(kind: .copy, name: "video.mov",
                       src: "/Users/me/video.mov", dst: "server:/data/",
                       total: 62_914_560, direction: "Mac → server",
                       cleanRoot: "/data", cleanIsRemote: true))

TransferList(queue: queue)                         // карточки
TransferRing(job: queue.jobs[0])                   // кольцо у строки файла
```

Связь вернулась — `queue.linkUp()`; приложение закрывается или связь пропала — `queue.stopAll("нет связи")`.

## Оговорки

- `/usr/bin/rsync` в новых macOS — openrsync; `--progress`, `--partial-dir`, `--bwlimit` работают (проверено
  на macOS 26). Свой rsync — поменять путь в `TransferQueue.run`.
- `total` нужно знать заранее (в Lab — `du` перед копированием); без него полоса показывает только «передано».
- Тексты интерфейса — по-русски, как в Lab.
