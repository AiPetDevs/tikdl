Своим людям TikDL отдавать уже можно; для широкой раздачи не хватает подписи, автообновления и защиты от переполнения диска

Самое опасное (чужие ссылки, выход за папку, раздача скачанного) закрыто. Остались три группы: доверие к самому приложению, место на диске и честность размеров, удобство.

Состояние на 23.11.2026, после исправлений P0, P1 и переделки интерфейса.

Вопрос: «какие слабые места остались у приложения?»

Суть

Приложение передаёт файлы напрямую между компьютерами по ссылке. Безопасность передачи теперь в порядке, а «внешняя оболочка» — нет. macOS и Windows не узнают в TikDL доверенную программу, исправления не доходят до людей сами. Сама программа не проверяет, хватит ли места на диске, и временно занимает его вдвое. Ниже — по степени вреда.

Доверие и безопасность

Слабое местоЧем грозит
важноНет подписи и нотаризацииmacOS предупреждает «не удалось проверить разработчика», Windows — SmartScreen. Людям приходится обходить защиту системы вручную. Нужен ваш сертификат Apple Developer (и для Windows — сертификат или Azure Trusted Signing).
важноНет автообновленияИсправление ошибки или дыры не дойдёт до тех, у кого приложение уже стоит. Нужен ключ подписи обновлений.
среднеСсылка раскрывает IP-адрес раздающегоЛюбой, у кого есть ссылка, видит ваш адрес в сети. Лечится режимом «в ссылке только адрес посредника (relay)» — соединение всё равно найдётся.
среднеСсылка вечная и для всехПока раздача идёт, скачать может любой, кому переслали ссылку. Нет срока действия, ограничения числа скачиваний и счётчика «кто уже скачал».
мелкоПодтверждение верит словам отправителяВ окне «Скачать?» размер и имя — из ссылки («со слов отправителя»). Настоящие приложение узнаёт только после согласия: это сознательно, чтобы до вашего решения никуда не подключаться.
мелкоМетаданные чужой раздачи без предела размераСписок имён файлов приложение берёт у отправителя целиком. Злонамеренный отправитель может прислать огромный список. Нужен потолок — несколько мегабайт.

Место на диске и надёжность

Слабое местоЧем грозит
важноНет проверки свободного местаЗагрузка 50 ГБ на диск с 20 ГБ свободного дойдёт до конца места и упадёт, забив диск.
важноСкачанное временно лежит дваждыСначала данные копятся во внутреннем хранилище, потом выкладываются в папку, а внутренняя копия стирается через ~5 минут. Для 4 ГБ нужно ~8 ГБ свободного.
среднеРаздача живёт, только пока открыто окноЗакрыли окно — ссылка перестала работать. Нет значка в строке меню, чтобы раздавать в фоне.
среднеИзменённый во время раздачи файлРаздаётся «как есть на диске». Если файл поменять, получатель получит ошибку проверки. Пометка «файлы изменились» надёжно появляется после перезапуска; поведение в момент правки — оценка, не проверял.
среднеWindows и Linux не проверены вживуюСборка для них описана, но ни разу не запускалась; сборка на GitHub тоже не запускалась. Проверен только macOS.
мелкоОтправитель не в сети в момент стартаЕсли в ссылке нет размера, приложение 15 секунд ждёт ответа, потом качает без доли («передано N»). Не проверено вживую.

Удобство

  • Ссылки tikdl:// не кликабельны в Telegram, WhatsApp, почте — нужна страница-прокладка в интернете, которая открывает приложение или предлагает его скачать.
  • Нельзя перетащить файлы в окно, выбрать несколько файлов сразу, показать ссылку QR-кодом.
  • Нет уведомления «Готово», нет кнопки «очистить завершённые», папка назначения не запоминается между запусками.
  • Перед скачиванием не виден состав раздачи (какие файлы внутри).

Сам проект

  • Нет истории версий (git). Откатить неудачную правку можно только из ручных копий. Это первое, что стоит завести.
  • Проверки интерфейса (чистота кода, снимки экранов) запускаются вручную, в автоматическую сборку не включены.
  • Проверка стиля кода Rust (clippy) ни разу не запускалась: здесь её не удалось установить.

Что я бы делал дальше — по порядку

  1. Завести git — дёшево, защищает всё остальное.
  2. Проверка места на диске перед загрузкой и потолок на размер списка файлов — полдня.
  3. Подпись, нотаризация и автообновление — когда будут ваши сертификаты.
  4. Значок в строке меню (раздача при закрытом окне) и страница-прокладка для ссылок.
  5. Режим «без IP в ссылке», срок действия ссылки, счётчик скачиваний.
